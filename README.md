# Roguelike Game Demo

一个基于 EasyX 图形库开发的 Roguelike 风格游戏演示项目，包含角色控制、敌人追踪、碰撞检测、动画效果等核心游戏功能。

## 项目简介

![示例](https://cdn.jsdelivr.net/gh/lvjianchaos/Images/note/main.png)

本项目是一个简易的 Roguelike 游戏原型，实现了以下核心功能：

- 游戏启动界面与交互按钮（开始 / 退出）
- 玩家角色移动控制与动画效果
- 敌人自动生成与追踪机制
- 碰撞检测系统（玩家与敌人、子弹与敌人）
- 基础动画帧管理与渲染

## 环境要求

- 操作系统：Windows（基于 EasyX 图形库，仅支持 Windows）
- 开发环境：Visual Studio 2022（支持 x64 编译）
- 依赖库：[EasyX](https://easyx.cn/) 图形库

## 安装与运行

1. 克隆或下载本仓库到本地
2. 使用 Visual Studio 打开项目文件（.vcxproj）
3. 确保已安装 EasyX 图形库（安装后会自动配置链接库）
4. 编译项目（支持 Debug 和 Release 模式，默认输出到 x64 目录）
5. 运行生成的可执行文件（`x64/Debug/Project1.exe` 或 `x64/Release/Project1.exe`）

## 游戏操作

- **启动界面**：点击 "开始游戏" 按钮进入游戏，点击 "退出游戏" 按钮关闭程序

- 游戏中：
  - 使用方向键（↑↓←→）控制玩家移动
  - 玩家自动面向移动方向（左右动画切换）
  - 敌人会从屏幕边缘随机生成并追踪玩家
  - 子弹可击中敌人（具体发射方式可根据扩展逻辑实现）

## 代码结构说明

- **核心类**：
  - `Button`：按钮基类，处理点击、悬停状态与渲染
  - `Player`：玩家类，管理移动、动画与碰撞检测
  - `Enemy`：敌人类，实现生成、追踪、碰撞与销毁逻辑
  - `Animation` & `Atlas`：动画帧管理系统，处理角色动画播放
  - `Bullet`：子弹类，实现基础子弹渲染与碰撞判定
- **关键功能**：
  - 半透明图像渲染（`putimage_alpha`）
  - 角色移动向量计算与边界限制
  - 敌人智能追踪算法（基于玩家位置的方向向量）

  - 帧动画时间控制
